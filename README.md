# azota-games-privacy

**엘리멘탈 체인**(AZOTA GAMES)의 개인정보처리방침을 담는 저장소입니다.
GitHub Pages 로 공개되어 Google Play Console 의 「개인정보처리방침 URL」에 씁니다.

    https://mozzidoda.github.io/azota-games-privacy/

- `index.html` — 방침 본문 (한국어 · 영어, 14개 조항)

원본은 게임 저장소의 `docs/privacy/index.html` 입니다.
**앱이 수집하는 것이 바뀌면 두 곳을 함께 고쳐야 합니다.** 안 고치면 정책 위반입니다.

특히 Realtime Database 를 `asia-southeast1`(싱가포르)이 아닌 곳에 만들면
**제6조(국외 이전)** 의 이전 국가를 고쳐야 합니다.
